# -Forest-Edition-v2.0
🌲Forest Edition — Cozy Interactive Web Card
A cozy, interactive 3D web application built with pure HTML, CSS, and JavaScript. Explore the peaceful forest, interact with the environment, and enjoy the ambient sounds! ✨
✨ Features
Day & Night Modes: Click the sun or moon to switch between a sunny day and a starry night with custom lighting and ambient audio.
Interactive Pine Trees: Tap on the pine trees to shake them and watch needles drop!
Cozy House Controls:
Toggle the window light on/off (and spot a secret cat friend in the dark window 🐈‍⬛💚).
Open and close the front door 🚪.
Turn the chimney smoke on/off 💨.
Friendly Bird: Tap the cute blue-breasted bird to hear it chirp and watch musical notes float up 🐦🎶.
3D Parallax Tilt Effect: Smooth mouse and touch tilt animations that bring the card to life.
Fully Responsive: Perfectly scaled for all desktop monitors, tablets, and mobile phones.
🛠️ Technologies Used
HTML5 / CSS3 (Flexbox, Grid, CSS Variables, Custom Animations, 3D Transforms)
JavaScript (ES6+) (Web Audio API for procedural sound effects, DOM manipulation)
